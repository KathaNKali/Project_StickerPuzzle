# 003: Reverse-construction generator

**Date:** 2026-11-05 (decided by designer in planning; recorded here)

**What:** Boards are built by placing blocks in reverse removal order, then a validator replays the removal order. Details: [waves-and-generator](../design/waves-and-generator.md).

**Why:** Every wave comes with a built-in solution, so solvability is proven rather than searched for. The same seed gives the same board.

**Alternatives rejected:** Not recorded in the planning summary.
