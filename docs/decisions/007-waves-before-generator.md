# 007: Wave system before generator

**Date:** 2026-11-07

**What:** Build the wave system first with 5 hand-made dummy levels, then the generator scene that creates and saves real levels.

**Why:** The designer's choice. The full core loop becomes playable sooner, and the generator then feeds a game that already works.

**Accepted risk:** The dummy levels say little about whether real levels are interesting; that is judged after the generator exists.

**Alternatives rejected:** Generator first: core gameplay would come later.
